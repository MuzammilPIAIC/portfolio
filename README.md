# Muhammad Muzammil & MK Systems — portfolio

Static HTML, CSS, and JavaScript. No build step or backend. Open index.html in a browser or serve this directory with `python -m http.server 4173`.

## Content

Includes professional experience, skills, education, certifications and submitted open-source contributions from the supplied CV, along with the owner's stated digital solutions services and clients. The original CV is included for download. The role marked Present follows the supplied CV. MK Systems is the owner-selected business name. The header switches between Muhammad Muzammil (m·m) in Myself and MK Systems (m·k) in My Business. The footer, business introduction, contact copy, and metadata also carry the business identity. GitHub and Upwork links were omitted because the CV does not provide unambiguous profile URLs. LinkedIn uses the supplied muzammil-ai handle.

Client names: Naqsh Nigar and Insaf Fabrics. Project scopes, results, screenshots and testimonials have not been invented.

## Interaction

Persistent section buttons change the selected content and scroll to it. The hero also changes for each view. The pinned toolkit sequence transitions through three scenes as the visitor scrolls; its three controls allow direct scene navigation. Reduced-motion mode shows all three scenes in a standard layout. Buttons have keyboard focus styling. Email and phone links use native mail and dial handlers.

## Publish on GitHub Pages

Upload index.html, style.css, app.js, theme.js, Muhammad-Muzammil-CV.pdf and .nojekyll to the repository root. In Settings → Pages, choose Deploy from a branch, select your publishing branch and / (root), then Save. Relative asset paths support project and account Pages URLs. Include the CV only if you want its full contact details publicly downloadable.

Google Fonts is optional, with system fallbacks. No external JavaScript, API keys or build dependencies. This local version has not been uploaded or published.

## Appearance

The eclipse dial in the header switches between dark and light palettes. Dark is the initial default. The selected palette is saved locally when browser storage is available; the switch still works when storage is blocked. The icon and accessible button label show the mode available on the next click. Reduced-motion preferences disable its animation.
